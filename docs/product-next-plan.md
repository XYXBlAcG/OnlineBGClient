# 后续体验功能（待审核）

本页功能均暂不实施。已交付能力统一见 [架构](architecture.md)，AI 接入独立见 [卡坦岛方案](catan-ai-plan.md)。不增加云端部署或语音。

| 顺序 | 痛点与拟定功能 | 验收规则 |
| --- | --- | --- |
| 1 | 手机临时切后台导致整桌暂停：可配置断线宽限、返回后的自动恢复 | 断线可见，宽限到期才暂停；离线玩家不能被自动出牌；对局与聊天均不重复提交 |
| 2 | 看不清手机手牌、频繁滚动：游戏专属手牌抽屉、放大牌与触屏选牌 | 公共牌桌与私人手牌分开；横竖屏保留本地选择；有副作用的动作只提交一次 |
| 3 | 新玩家不知道下一步：合法目标高亮、阶段提示、规则就地说明 | 提示由合法动作与当前规则派生；不泄露隐藏信息；老玩家可关闭辅助 |
| 4 | 聚会时多人围着小屏幕：电视／大屏公开牌桌、独立观战身份 | 公开视图不展示任何人的手牌；观战者不占席位、不触发暂停；聊天权限可由房主选择 |
| 5 | 手机切网络后不知哪里出了问题：连接诊断和可导出的诊断摘要 | 区分网络往返、服务处理与本地渲染；显示最后同步时间；诊断不包含恢复凭据或私人手牌 |
| 6 | 每次配置同一组玩家都很繁琐：聚会模板与轮换安排 | 模板保存游戏、人类／AI 席位与主题；应用时确认移除成员和结束当前局；复用同一个房间入口 |
| 7 | 临时公网地址变化后难恢复：一次性恢复码与重新邀请 | 新入口恢复既有席位；重复恢复时旧连接退出；不要求用户复制内部 token |
| 8 | 长对局争议难排查：回放时间轴、事件筛选、局面书签和分享导出 | 私密回放只在对局结束后开放；书签关联事件编号；导入校验规则版本 |
| 9 | 玩家暂时有事：离席与 AI 托管 | 仅支持已有策略的游戏；恢复真人控制有明确边界，不在一次决策中切换操作者 |

优先建议审核前四项，它们直接改善手机聚会和新玩家入门。自动更新仍按 [更新方案](roadmap.md#自动更新方案待实施) 另行实施。

备用电脑接管需要转移权威服务和存档，并重新建立公网入口；手机浏览器不能直接承担当前房间服务。若需要这项能力，应单独设计和验证，不用浏览器房主权限替代服务迁移。
