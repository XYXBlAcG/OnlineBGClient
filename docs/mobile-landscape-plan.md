# 手机横屏与聊天表现

界面操作由用户手动验收。手机横竖屏使用同一份游戏状态与专属牌桌，不重置手牌选择或聊天草稿；统一入口见 [视口](../src/client/use-mobile-viewport.ts)、[横屏排列](../src/client/ui/mobile-landscape.css)、[原站区域适配](../scripts/upstream-table-regions.mjs)。现有其他入口见 [房间与聊天](mobile-social-experience.md)。

## 使用

手机旋转为横屏后自动采用横屏排列，仍可自行进入「沉浸牌桌」。聊天按需打开侧边抽屉；菜单、引导和外观通过现有房间入口访问。键盘出现时可用高度与聊天位置由统一视口处理。

中央标题默认金橙色，红金示例为 `/title --style red 绝地反击`。文字样式、长标题布局与动画开关见 [表现层](../src/client/social/BannerLayer.tsx)、[样式](../src/client/ui/social-experience.css)。本机显示偏好与房主授权继续生效。

聊天中的图片档位可选择「清晰」或「省流」，发送前预览显示实际输出像素、大小和档位。切换档位会重新处理待发送图片；超出硬上限时保留原文件供重新选择档位，不继续静默降质。查看大图可切换「实际像素」。格式、分辨率、质量和缓存预算的唯一来源见 [图片策略](../src/domain/attachments.ts)，传输见 [媒体处理](../src/client/social/media.ts)。

输入 `/` 或打开「指令」查看所有示例。指令目录同时提供解析、帮助、补全和权限分类，定义见 [指令模型](../src/domain/banner.ts)，服务校验见 [房间](../src/domain/room.ts)。公告、倒数与表情连击沿用横幅授权；清屏只允许房主管理者。倒数只提醒，不自动开局；娱乐骰子不替代任何游戏内骰子，结果随消息保存，回放不会重新掷骰。

## 手动验收

1. 在 iOS Safari 和 Android Chrome 中打开房间，横竖屏互转；重复打开键盘、收起键盘和聊天抽屉，检查刘海、浏览器工具栏、发送按钮与底部安全区。
2. UNO、斗地主、三国杀检查长手牌和最大人数：自己手牌与必要动作可达，对手头像可以完整辨认；旋转前的手牌选择保留，左右滚动不会误出牌。三国杀同时检查选将阶段、锦囊与武将详情。
3. 四川麻将分别检查换三张、定缺、出牌与碰杠胡响应；手牌、牌河和头像可操作，不因旋转丢失选择。
4. 飞行棋、跳棋与卡坦岛先缩放、拖动地图，再旋转，检查缩放保持、视图未跑出边界，棋格和建造点的实际命中正确；卡坦岛交易、发展卡与资源操作完整可达。
5. 璀璨宝石检查市场、宝石与收藏，展开和折叠收藏不挤没市场；毒药检查药锅和长手牌。分别对比正常界面与沉浸牌桌。
6. 浅深色下检查聊天浮层、设置页与独立聊天窗口的「本机显示横幅与全屏表情」：轨道不拉长，文字不覆盖，开启和关闭状态清楚；重开应用后偏好仍保留。
7. 同一张含小字的截图、牌面照片和普通照片分别使用清晰档与省流档；比较发送前预览、另一设备收到的大图和实际像素模式。PNG 透明区域正确，图片超限可重新选档，上传期间仍能出牌。
8. 发送金橙和红金中央大字，检查长文字、横屏低高度、聊天键盘、关闭游戏动画与系统减少动态效果；动画不挡点击、不频闪。
9. 普通玩家未获授权不能发横幅；房主授权后可发公告、倒数与连击。倒数结束不自动开局；房主清屏后所有设备立即停止横幅，普通玩家不能清屏。
10. 未获横幅授权的普通玩家仍可发送娱乐骰子和行为描述；重复请求不产生新骰子。对局结束后回放到相应步骤，骰子结果不变；本机关闭横幅仍生效。

结构渲染、单位测试和构建不代表上述真实设备界面已通过。性能与网络检查采用协议和存储入口，不启动浏览器或桌面界面自动化。
