# 麻将

大厅选择「麻将」，再选择「四川血战」「日本立直」或「瓦西子透明麻将」。房间邀请使用房主选定的模式。四川血战规则与回归入口见 [四川麻将](sichuan-mahjong-plan.md)。

## 日本立直

四人东风战、136 张牌、隐藏他家手牌，复用立直核心的吃碰杠、立直、振听、宝牌、里宝牌、抢杠、多家和牌与番符计分。每局结束显示下一局和本场信息；庄家和牌连庄，非庄家和牌轮庄，立直棒跨局保留，流局按听牌与庄家连庄规则推进，点到负数或东四局结束。模式选择、动作与投影见 [类型](../src/domain/mahjong/types.ts) 和 [立直规则](../src/domain/mahjong/washizu.ts)；牌桌与 AI 复用 [日本／透明牌桌](../src/client/mahjong/SichuanTable.tsx) 和 [策略](../src/domain/mahjong/strategy.ts)。[定向测试](../tests/mahjong-washizu.test.ts) 覆盖牌数、他家暗手牌遮蔽、立直计分与合法动作。

[新手引导](../src/client/BeginnerGuide.tsx) 为四川、日本立直和透明模式分别提供图形化牌面、牌形、役、宝牌、立直、振听与副露步骤；[练习场](../src/client/Practice.tsx) 使用真实规则和本地教学 AI，不发送到真实房间。

## 瓦西子透明麻将

四人东一局，各 25,000 点。每种牌三张透明、一张暗牌。蓝色边角标识透明牌，他家公开手牌区显示透明牌面和暗牌背。牌墙顺序和未翻宝牌只保存在房间权威状态中。单局支持立直、振听、吃碰杠和番符计分，使用普通五，不配置赤宝牌。和牌或牌墙耗尽时结算。支持多人荣和，立直棒由距出牌者顺位最近的和家领取。流局结算听牌点数，单局立直棒退还宣告者。

- 模式与动作入口见 [类型](../src/domain/mahjong/types.ts)。
- 回合、响应、结算及遮蔽见 [透明规则](../src/domain/mahjong/washizu.ts)，役种和点数复用 [立直计分适配](../src/domain/mahjong/riichi-hand.ts)。
- [牌桌](../src/client/mahjong/SichuanTable.tsx)复用四人席位与动作区，[AI](../src/domain/mahjong/strategy.ts)使用自己手牌、公开牌和合法动作。
- [定向测试](../tests/mahjong-washizu.test.ts)覆盖牌数、公开投影、吃牌、立直自摸、振听、整局结算与回放。回放只在对局结束后交付，界面按所选视角遮蔽暗牌。

人工验收时在本地和公网分别建立四人房，核对模式选择、透牌与字牌显示，完成一次立直和一次流局。再检查不同座位、手机横竖屏、浅深主题和断线恢复时的手牌可见性。
