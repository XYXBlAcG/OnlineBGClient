# 手机版与电脑版能力对照

范围：电脑版指 Tauri 桌面客户端；手机版指 SwiftUI 原生壳 + WKWebView 牌桌。手机浏览器单列，仅作对照。实现入口以代码为准，本页只维护差异和建议，不复制游戏规则。

## 能力对照

| 能力           | 电脑版                                     | 手机原生版                                        | 手机浏览器         | 说明                              |
| -------------- | ------------------------------------------ | ------------------------------------------------- | ------------------ | --------------------------------- |
| 安装与更新     | 桌面安装包、自动更新                       | Xcode 签名构建，`ideviceinstaller` 安装；后续 IPA | 无需安装           | 安装后单机不依赖电脑              |
| 首页           | 桌面大厅、最近房间、创建/加入              | SwiftUI 首页、最近游戏、继续远征、加入            | 手机加入页         | 手机没有创建房间                  |
| 本地开局       | 支持全部游戏、AI 配置                      | 支持全部手机游戏、1 真人 + 多 AI、AI 难度/响应    | 不支持本地开局     | GraphWar 明确不在手机目录         |
| 创建房间       | 公网/LAN 房间、邀请链接、二维码            | 不支持创建，仅加入                                | 不支持创建         | 手机开房在后续远程宿主方案        |
| 加入房间       | 链接、最近房间                             | 链接、二维码、最近加入、玩家/旁观                 | 链接               | 手机加入后加载 Web 房间           |
| 房间等待与准备 | 完整等待室                                 | Web 房间等待室；原生返回/原生错误提示             | Web 等待室         | 手机不维护第二套房间状态          |
| 牌桌           | 桌面牌桌，鼠标/键盘/悬停                   | WKWebView 手机牌桌，触控，无悬停                  | 手机牌桌           | 规则和状态同一套 Web 实现         |
| 横屏           | 普通窗口布局                               | 手机专属横屏 CSS；原生导航隐藏，保留返回          | 手机横屏 CSS       | 逐款视觉仍需真机审核              |
| 聊天           | 侧栏聊天、图片、常用语、语音栏             | 本地无聊天；联机使用 Web 右下角聊天               | 聊天侧栏           | 原生不再放第二套聊天组件          |
| 语音           | LiveKit 桌面语音、输出/变声                | 暂未接入                                          | 不支持             | 手机原生语音仍是后续阶段          |
| 新手引导       | 支持                                       | 手机端隐藏，避免遮挡牌桌                          | 手机端隐藏         | 桌面不受影响                      |
| 记录/回放      | 记录页、回放、成就                         | 原生壳暂无入口                                    | 加入房间内可看记录 | 后续可接原生记录入口              |
| 设置           | 主题、显示、语音、网络、计算、快捷键、更新 | 主题、增强动效、版本/构建                         | Web 设置           | 原生壳不复制桌面设置              |
| AI 计算        | 线程、基准、审计、性能设置                 | 设备本地 AI；远征可调 AI 响应                     | 不适用             | 手机算力和耗电策略不同            |
| 存档/继续      | 本地对局、远征 RunShelf、联机恢复          | 远征「继续远征」；本地/联机 RunShelf              | 加入房间恢复       | 其他游戏的本地存档入口仍可后续补  |
| 邀请二维码     | 生成邀请与二维码                           | 扫描二维码、粘贴链接                              | 系统相机           | 手机生成邀请仍依赖桌面房主        |
| 提示与确认     | Web 横幅/对话框                            | 错误通知和确认框改为 iOS Alert                    | Web                | 一次只保留一种消息来源            |
| 辅助窗口       | 桌面聊天/设置等辅助窗口                    | 无                                                | 无                 | 手机不需要桌面多窗口              |
| 插件工坊       | 安装、启用、禁用插件                       | 不展示                                            | 视 Web 页面        | 插件属于桌面能力                  |
| 快捷键         | 可配置全局/应用快捷键                      | 不展示                                            | 无                 | 手机触控优先                      |
| 后台/性能      | 常驻桌面、计算线程                         | WKWebView 生命周期；无后台房主                    | 浏览器后台         | 手机不能承担长期房间服务          |
| 数据位置       | 本机 IndexedDB/文件                        | Web 产物内置；WKWebView 持久化 IndexedDB | 浏览器存储         | 单机走 App 内 `127.0.0.1` 静态服务 |
| 版本识别       | 桌面版本信息                               | 设置页显示版本/构建，如 `0.4.1 (4)`               | Web 版本           | 每次签名安装递增构建号            |

## 本轮已对齐

- 手机错误横幅改为原生提示；Web 错误横幅隐藏，成功轻提示保留。
- 本地牌桌不显示聊天；联机房间只保留 Web 聊天按钮。
- 游客对局中离开不再报“请先结束对局再离开”，支持的游戏转 AI 接管。
- 手机隐藏新手引导。
- 秘塔远征使用“AI 朋友 / AI 能力”，职业选择两列、战斗底部手牌、横屏左操作右场景。
- 远征开局可选剧情/标准/挑战难度；职业、卡牌和地图图标统一为文本字形，头像保留 emoji 内容。
- 手机远征把队伍、路线、牌组、职业详情和托管收进抽屉；桌面上队伍和操作直接显示，路线保留侧栏。
- 秘塔远征横屏地图在手机横屏自动启用；桌面可在路线面板切换，并记住上次选择。
- 新增「继续远征」：原生打开 Web `RunShelf`，复用本地/联机存档和 `restore-run`。
- 新增 AI 响应设置：本地开局通过 `aiDelayMs` 写入房间配置，局内不再提供原生速度菜单。
- 原生加入房间现在从统一 Shell 基址加载，再用 `service` 参数连接房间服务，避免 IndexedDB 分裂。

## 建议实现顺序

### P0：先把手机闭环做稳

1. 远征存档恢复成功提示；失败提示和放弃确认已接入原生 Alert，继续验证。
2. 联机远征存档：验证 Shell 基址 + `service` 参数下的重连、退出和房主离线。
3. 验证手机玩家/旁观席、房主关闭确认和邀请二维码完整流程。
4. AI 响应：房主节奏修改会推进房间版本并随快照下发；客人不显示编辑控件。
5. 逐款横屏真机修复：远征横屏地图已完成；优先三国杀、麻将、卡坦岛、领土。

### P1：手机独立能力

1. 原生 LiveKit 语音：按 [iOS 计划](ios-app-plan.md) 接入，不在 WebView 上做补丁。
2. 原生对局记录/回放入口：只展示，不复制记录状态。
3. 手机通知、触感反馈和后台切换恢复。
4. 图片/常用语在联机 Web 聊天中的手机尺寸优化。

### P2：需要服务端或分发支持

1. 手机开房：远程宿主或云端房间服务，见 [手机远程开房](remote-host-plan.md)。
2. IPA 签名、侧载、更新和版本兼容提示。
3. 插件工坊、桌面辅助窗口、快捷键：保持桌面专属，不移植到手机。

## 不建议实现

- 不做第二套原生游戏牌桌；规则和状态继续只由 Web 引擎维护。
- 不再做原生聊天双入口；手机本地无聊天，联机只用 Web 聊天。
- 不在手机端开放桌面计算、插件、辅助窗口和快捷键设置。
- 不把手机房主、语音、插件等未完成能力先做成假入口。
