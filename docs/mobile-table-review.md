## 手动检查

以下界面交互由用户执行。电脑打开审核客户端并创建房间，手机使用此次客户端生成的邀请链接，刷新后再检查。

1. 飞行棋、跳棋分别检查手机竖屏与横屏：进入「沉浸牌桌」，应只保留牌桌、必要游戏操作和浮动聊天入口；无顶部栏、房间管理区和地图工具栏。
2. 双指放大、缩小棋盘，单指平移；轻点棋子或落点仍能操作，拖动与缩放不应误出棋。跳棋确认移动、飞行棋掷骰仍可用。
3. 打开聊天、输入文字、收起聊天，棋盘仍停留在沉浸模式；聊天抽屉内「恢复界面」可找回房间控制。对局结束后应显示结束状态与继续游戏入口。
4. 手机加入页、房间和聊天抽屉内分别选择浅色、深色、跟随系统；刷新后保留选择。电脑通过设置切换。逐个游戏检查牌桌文字、控件、棋格与牌面，彩色棋子和宝石应保持可辨识。
5. 电脑粘贴完整邀请链接加入并恢复原身份；只输入房间号、缺少房间信息的链接或非 HTTP 链接应提示错误，不能误连默认服务。
6. 在没有活动公网房间时测试创建失败：界面显示尝试次数，达到上限后提示重新操作；手动恢复网络后可再次创建。中途取消后不应继续重试或留下活动服务。

本地定向单元测试与编译不代表已完成手机实机、Windows 或公网人工验收。
