# 手机房间与聊天互动

手机等待室的「房间菜单」集中提供游戏与人数、新手引导、外观和管理操作；开局后才出现沉浸入口。桌面与手机复用 [房间工具栏](../src/client/RoomToolbar.tsx) 和 [基础控件](../src/client/ui/Controls.tsx)。

## 使用

房主在「房间菜单 → 横幅与全屏表情」选择仅房主、房主和指定玩家、所有玩家或禁止发送。指定对象按房间身份保存，离开或被移除后撤销。仅启动服务时，服务端房主与首位手机管理者沿用现有房间管理权限。

聊天输入 `/` 查看补全，点击「指令」查看示例和表情选择。文字横幅、底部提示与全屏表情均不阻挡点击；普通聊天不需要横幅授权。指令、长度、时长和权限的唯一定义见 [横幅模型](../src/domain/banner.ts)、[房间校验](../src/domain/room.ts)。

「设置 → 消息与互动」或聊天工具栏的「显示」可关闭本机横幅与全屏表情；关闭后仍保留聊天文字，不影响其他玩家。游戏动画开启时提供增强表现，关闭时使用静态横幅，系统减少动态效果优先。声音开关和音量位于同一设置页；手机需要先有一次正常交互才能启用声音。

聊天「图片」选择静态图片，或在桌面消息输入框中粘贴图片；压缩后预览，再点击发送。支持格式与预算见 [图片限制](../src/domain/attachments.ts)。不支持的格式需自行转换；第一版不提供动态图或贴图库。失败后可重试或取消。

本地图片在「设置 → 数据 → 聊天图片缓存」清理。房主另可清理当前联机房间的图片，影响该房间全部玩家；其他玩家已加载的预览会保留到关闭，后续加载显示已清理。公网图片保存在房主电脑，关闭房间后的保留期见 [图片限制](../src/domain/attachments.ts)。游戏回放仅记录横幅注释，不永久打包图片附件。

## 手动验收

1. 手机竖屏进入等待室，检查长游戏名、人数和邀请按钮；无沉浸按钮、无常驻外观下拉。房间菜单中修改主题和游戏，准备与开始等高且不挨在一起。再检查横屏与软键盘。
2. 房主发送 `/title 好牌！`、`/subtitle 下一局换游戏`、`/actionbar 轮到你啦` 与 `/effect 🤣`；显示期间继续选择手牌或棋子。开关游戏动画，比较动态和静态效果。
3. 普通玩家未授权发送应被拒绝；房主指定该玩家后允许，撤销后立即拒绝。改昵称或重连不产生新授权。连续发送受频率限制。
4. 在一台手机关闭本机横幅，该手机只收到聊天文字，其他设备照常显示；重新开启不播放历史横幅，切后台再返回不刷屏。
5. 从手机选择大图，确认压缩进度、大小、预览与取消。发送后所有玩家查看图片和时间；桌面输入框粘贴图片，独立原生聊天窗口重复检查。上传期间继续正常出牌。
6. 断网时上传应可中止或重试；重连后不会重复发送消息。其他房间无法读取附件。清理房间图片后用另一设备重新加载旧消息，应显示已清理。
7. 打开回合提示音并调低音量，检查本人回合、阶段切换、非法操作和结算；静音后无声音，AI 快速行动时不会密集叠音。
8. 对局中发送横幅，结束后回放到对应步骤；只在对应步骤显示，不改变牌局结果。检查暂停、跳转、减少动态效果。

上述界面步骤由用户执行。HTTP／WebSocket、文件存储与内存组件检查不等同真实 iOS、Android 或 Windows WebView2 验收。
