# 手机牌桌审核

公共入口：[手机尺寸策略](../src/client/ui/mobile-usability.css)、[房间工具栏](../src/client/ui/social-experience.css)、[横屏布局](../src/client/ui/mobile-landscape.css)。游戏规则及状态继续复用原牌桌，未建立第二份手机游戏实现。

手机入口只展示 [游戏目录](../src/domain/catalogue.ts) 中 `mobile` 为 `true` 的游戏；GraphWar 标记为不可用，秘塔远征等单人或 AI 补位游戏可用。新增游戏时只维护目录中的这一字段，不在页面另建名单。

在 [手机预览](phone-preview.md) 及真实手机中人工审核以下项目；每款均检查横屏、竖屏、聊天打开与关闭、夜间模式、退出游戏及返回房间。

| 游戏 | 重点人工操作 |
| --- | --- |
| 三国杀 | 选将、技能说明、选择目标、浏览并打出手牌 |
| 四川麻将 | 换三张、定缺、横滑手牌、碰杠胡、查看三家弃牌 |
| UNO | 横滑手牌、选色、摸牌、多人头像 |
| 斗地主 | 横滑与多选手牌、叫分、出牌及不出 |
| 飞行棋 | 缩放地图、拖动定位、选棋与掷骰 |
| 跳棋 | 六人棋盘、选棋和连续跳跃 |
| 卡坦岛 | 地图缩放、建造、交易、资源与发展卡 |
| 璀璨宝石 | 横向浏览市场、取宝石、预留与购买、玩家收藏 |
| 毒药 | 三个锅、选牌、收牌与玩家信息 |
| 领土 Dominion | 供应区、手牌、购买与响应选择 |
| 秘塔远征 | 地图、敌人意图、手牌、商店与卡牌服务 |

结构覆盖使用真实房间开局并渲染牌桌：[定向测试](../tests/mobile-usability.test.tsx)。自动验证只检查资源、结构及尺寸策略，不代表已完成截图或触屏体验验收；界面交互测试由用户执行。

聊天收放复用 [侧栏动画](../src/client/AnimatedSidebar.tsx)，遵循界面动画与系统减少动态效果设置；生命周期检查见 [侧栏测试](../tests/sidebar-motion.test.tsx)。人工检查连续快速收放、关动画后收放，以及横屏麻将工具栏文字不拆行、三家玩家和自己的手牌互不覆盖。
