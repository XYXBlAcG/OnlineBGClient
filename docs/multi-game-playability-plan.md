# 多游戏可玩性扩展规划

本规划面向秘塔远征之外的游戏。优先增加会改变决策、局势反转和重复游玩价值的内容，不通过单纯增加卡牌、数值或动画堆积复杂度。

统一入口：[游戏目录](../src/domain/catalogue.ts)、[内置规则](../src/domain/builtin-rules.ts)、[房间配置](../src/domain/protocol.ts)。

## 优先级

| 优先级 | 内容 | 原因 |
|---|---|---|
| P0 | 统一的局内任务、每日规则、成就与数据页 | 所有游戏可复用，能快速增加目标感 |
| P1 | 每个游戏加入一个高差异模式 | 比继续增加普通选项更明显 |
| P2 | 赛季化场景、AI 风格和观战互动 | 延长生命周期，但依赖稳定基础 |

## 全游戏通用机制

### 局内契约

开局随机提供三项契约，完成条件后获得房间徽章、专属表情或历史记录，不直接破坏胜负规则。

- UNO：连续两轮不摸牌、最后一张使用数字牌。
- 斗地主：以单张关键牌完成翻盘。
- Catan：不依赖最长路获胜。
- Splendor：用低阶发展卡完成反超。

### 每日规则

同一日期使用相同种子和一组公开规则，例如“首轮禁止跳过”“所有交易公开化”。结果进入独立排行榜，不影响普通房间。

### 局势回放摘要

局后展示三个转折点、一次最佳操作、一次最大资源回撤和双方胜率变化，不只在远征中提供结算反馈。

## 各游戏方案

### UNO

- **团队 UNO**：2v2、3v3，队友手牌公开，胜利条件改为团队累计出完。
- **事件牌堆**：每若干轮翻一张全局事件，例如颜色轮换、跳过回合、手牌交换。
- **押注模式**：玩家可使用局内筹码抢先手或换牌，但会提高被集火概率。
- **终点保护**：首位只剩一张牌的玩家不会被连续无解惩罚，减少纯运气终局。

### 三国杀

- **剧情场景**：限定身份、限定武将和特殊胜利目标，例如护送、夺旗、坚守。
- **阵营任务**：每名玩家有一个公开主任务和隐藏副任务，避免身份局过度依赖首轮判断。
- **残局挑战**：固定牌序和手牌，要求玩家在限定轮数内完成目标。
- **观战预言**：旁观者预测下一轮阵亡角色，正确后获得派对积分。

### 四川麻将

- **牌局事件**：定缺后触发公开任务，例如保留指定花色、限制碰杠次数。
- **连续胡牌奖励**：不直接增加番数，而是提供局内表情、桌布和回放标记。
- **观战竞猜**：竞猜下一张关键牌或最终胡牌者，不参与正式结算。
- **双桌联赛**：多桌同时进行，累计桌分进入淘汰赛。

### 斗地主

- **叫分拍卖**：叫分同时消耗筹码，抢地主具有真实成本。
- **牌局目标**：使用指定牌型收尾、不拆炸弹获胜等可选契约。
- **明牌让分**：地主可以主动明牌换取更高收益，农民也可选择加倍反制。
- **残局模式**：固定手牌和底牌，提供确定性的战术谜题。

### 飞行棋

- **天气与地形**：顺风、雷暴、传送门和危险航线改变路线选择。
- **团队护送**：将一名队友全部送入终点才算胜利。
- **局内道具**：护盾、换位和拦截只能持有有限次数，避免无限拖延。
- **赛道事件**：赛道中段触发一次全体规则变化。

### 跳棋

- **非对称目标**：一方追求最短步数，另一方追求阻止达到阈值。
- **地形格**：单向格、传送格和冻结格，只在特定模式启用。
- **连跳奖励**：一次连续跳跃达到长度阈值后获得一次性技能。
- **团队跳棋**：每位玩家只控制部分棋子，必须协作完成路线。

### 毒药

- **配方牌**：满足特定颜色组合后解锁一次性药锅能力。
- **秘密任务**：每人开局获得隐藏目标，迫使玩家观察弃牌和颜色趋势。
- **市场阶段**：每轮公开一次交换机会，价格由剩余药锅空间决定。
- **污染事件**：特定组合触发全体规则变化，使风险判断更动态。

### 璀璨宝石

- **贵族契约**：贵族目标根据场上发展卡动态变化，而不是固定等待。
- **公共事件**：每三轮开放一次稀有宝石或预购卡牌。
- **竞争赞助人**：先达到某个组合的玩家获得一次性强奖励。
- **团队模式**：共享部分宝石但保留个人发展卡，强调资源协调。

### 卡坦岛

- **情景地图**：群岛、荒岛和资源枯竭地图使用不同生产规则。
- **事件牌堆**：丰收、风暴、迁徙和商队改变资源与道路价值。
- **秘密任务**：完成特定港口、道路或城市组合获得额外胜利点。
- **合作抗灾**：全体先完成公共目标，再比较个人贡献。

### Dominion

- **景观牌与事件牌**：当前已有构筑框架，可加入延迟收益、一次性事件和共享目标。
- **战役模式**：连续三局保留一张起始牌或一个王国牌修正。
- **AI 构筑倾向**：快攻、经济、引擎和控制四种公开策略，增强复盘可解释性。

### Graphwar

- **弹道禁区与风场**：表达式不变，但环境会改变轨迹。
- **有限弹药**：每轮只能使用指定函数类别，逼迫玩家调整策略。
- **目标模式**：护送核心、摧毁装置和占领区域，替代单纯击毁所有敌人。
- **残局挑战**：固定地图和函数限制，形成可分享的几何谜题。

## 实施顺序

1. 先做通用局内契约、局后摘要和每日种子入口，验证留存与复用价值。
2. 为 UNO、斗地主、飞行棋和跳棋各实现一个高差异模式。
3. 为三国杀、麻将、Catan、Splendor、Dominion 和 Graphwar 实现情景规则。
4. 最后加入赛季、排行榜、观战互动和跨游戏成就。

## 验收

- 新模式必须改变至少一个核心决策，不能只修改标题或数值。
- 每个模式都要有固定种子测试、AI 完整对局和回放兼容。
- 正式规则仍保持默认入口，实验模式可以独立配置和关闭。
- 新功能不能要求所有游戏同时修改；通过共享配置、结算和统计层复用。
