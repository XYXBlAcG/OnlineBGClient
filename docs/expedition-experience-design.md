# 秘塔远征体验量化与路线设计

## 目标

秘塔远征需要同时支持两种高峰体验：

- **越玩越爽**：构筑逐渐成形，职业资源、遗物、队友和牌组产生连锁，单回合可完成更多有效操作。
- **越玩越痛苦**：通过资源消耗、路线封死、不可逆风险和首领压力制造紧张感，但痛苦必须换来可见回报，不能变成单纯拖长战斗。

实现入口：[冒险状态机](../src/domain/expedition/adventure.ts)、[AI 路线评分](../src/domain/expedition/ai.ts)、[路线原型](../src/domain/expedition/route-profiles.ts)、[数学模型](../analysis/expedition-experience/model.ts)、[报告生成脚本](../scripts/analyze-expedition-experience.mjs)、[开发控制条](../src/client/expedition/DevExpeditionController.tsx)。

最新独立报告由 `npm run analyze:expedition-experience` 生成到 `artifacts/expedition-experience/report.html`，不参与游戏构建。

完整的 N0–N10 × 三难度扫描使用 `python3 scripts/run_expedition_difficulty.py`。`--games` 指定总运行数，`--seeds` 指定每个组合的运行数；`--seed-mode fixed` 使用连续固定种子，`--seed-mode random` 使用随机种子并将种子池写入 JSON。报告、原始结果和 SVG 图表生成到 `artifacts/expedition-difficulty-python/`。

```bash
python3 scripts/run_expedition_difficulty.py \
  --games 3000 \
  --workers 10 \
  --seed-mode random
```

```bash
python3 scripts/run_expedition_difficulty.py \
  --seeds 100 \
  --workers 8 \
  --seed-mode fixed \
  --start-seed 1000
```

`--games 3000` 会把 3000 局平均分配到当前选中的难度、阶位和人数组合。`--seeds 100` 则表示每个组合跑 100 局。

## 指标

每次节点结算和每个大层结束时记录以下公开量。数值只用于平衡，不参与玩家隐藏信息。

| 指标 | 定义 | 用途 |
|---|---|---|
| 战力净值 `PV` | `有效生命 + 格挡效率 + 每轮伤害 + 抽牌/能量 + 遗物触发价值` | 判断构筑是否持续变强 |
| 压力指数 `PI` | `敌方预计伤害 / (队伍治疗 + 可稳定格挡 + 资源保命)` | 判断战斗是否只剩血牛消耗 |
| 回报脉冲 `RP` | `节点总收益 / (生命、牌、遗物、金币与罗盘成本)` | 判断单节点“爽感”是否足够 |
| 选择宽度 `CW` | 当前合法路线数、不同节点类型数、绕过风险节点数 | 判断地图是否真正提供决策 |
| 不可逆成本 `IC` | 封商店、失去唯一遗物、消耗高强化牌、队友永久死亡等 | 约束痛苦路线的可恢复边界 |
| 回合参与度 `TA` | 每轮玩家有效操作数、同伴行动数、触发遗物数 | 防止自动化和固定循环吞掉玩家操作 |
| 构筑收敛度 `BC` | 主构筑标签贡献占总伤害、格挡和治疗的占比 | 检查是否只剩唯一解 |

体验评分建议先作为分析指标，不直接塞进玩家界面：

`Experience = 0.30 * normalized(PV growth) + 0.25 * normalized(PI) + 0.25 * normalized(RP) - 0.12 * frustration + 0.07 * CW`

`frustration = 连续两次无有效选择 + 三次以上资源负增长 + 不可逆损失未兑现回报`

## 两条体验曲线

### 越玩越爽

目标是在第三站开始出现小组合，在精英前后出现明确爆发，在首领前达到峰值，而不是最后只把敌人生命继续抬高。

- 普通战斗提供稳定牌组和金币，保证每场至少一个可见选择。
- 精英提供稀有遗物、队友或定向强化，回报脉冲显著高于普通战斗。
- 商店抢劫、深渊裂隙和限次队友属于高风险高回报节点：成功时让当前构筑跨过阈值。
- 遗物触发应鼓励组合而非线性叠数值，例如“热量换力量”“封牌换抽牌”“炮台叠回响”。
- 首领前两层应允许玩家看到至少一条构筑强化路线和一条恢复路线。

目标节奏：

| 阶段 | `PV` 相对首层 | `PI` | 主要体验 |
|---|---:|---:|---|
| 第 1–2 站 | 1.0–1.2 | 0.7–0.9 | 建立职业与基础牌组 |
| 第 3–5 站 | 1.3–1.8 | 0.9–1.15 | 首个遗物联动开始出现 |
| 第 6–9 站 | 1.8–2.6 | 1.1–1.35 | 构筑爆发，可主动挑战精英 |
| 首领前 | 2.4–3.5 | 1.25–1.55 | 用路线和资源换取最终构筑 |

### 越玩越痛苦

痛苦路线必须“可预见、可选择、可兑现”，不能靠隐藏惩罚制造挫败。

- 苦行线：消耗牌或遗物换取高额成长，节点中提前展示失去内容。
- 商店抢劫：24 回合内击败老板后本次全部商品免费，现有与后续商店永久变为空节点；超时则老板带走全部商品，后续商店保留。
- 深渊线：先消耗资源，再走固定长度的高随机支线；完成度必须清晰显示为当前支线第几层。
- 限次队友：只在实际出战且结束战斗后扣次数，阵亡或次数耗尽后离队。
- 不可逆死亡：只在玩家明确选择“易逝队友”时出现，并且当次战斗前再次确认是否上场。

痛苦曲线的硬边界：

- 不允许连续两个节点只扣资源、不提供选择或成长。
- 任何永久封死机制至少保留一条替代补强路线。
- 主线必须始终存在可达首领路径。
- 不可逆损失后，本大层内至少出现一次高价值补偿机会。
- 高难度增加的应是议程、组合与资源压力，而不是单纯增加 30% 以上生命。

## 路线原型

| 路线 | 成长方式 | 风险 | 目标玩家体验 |
|---|---|---|---|
| 滚雪球线 | 精英、遗物、商店与队友连续叠加 | 中高战斗密度 | 一旦成型，后程明显变强 |
| 苦行线 | 失去牌、遗物或商店，换取稀有资源 | 不可逆成本 | 精算与长期规划 |
| 赌博线 | 赌局、裂隙、未知事件 | 高波动 | 接受波动换爆发 |
| 构筑线 | 锻造、移除、职业牌池集中 | 首领针对性压力 | 牌组逐渐精准 |
| 伙伴线 | 招募不同存续规则的 AI 队友 | 阵容容量与永久死亡 | 用临时队友平滑前期，后期选择长期伙伴 |
| 恢复线 | 营地、奇遇、低风险战斗 | 收益较低 | 为高难路线保留翻盘空间 |

## AI 路线风格

[远征 AI](../src/domain/expedition/ai.ts) 支持六种公开信息风格，开发控制条可直接切换：

| 风格 | 路线偏好 | 用途 |
|---|---|---|
| 均衡探索 | 按生命、资源、风险和节点收益综合评估 | 正式对局默认策略 |
| 裂隙与回溯 | 提高裂隙、未探索回溯边、招募和事件的权重 | 验证支线、环路与新内容 |
| 精英猎杀 | 偏向精英和首领，降低营地权重 | 压测后期战斗力 |
| 稳健求生 | 偏向营地、商店，降低裂隙和精英权重 | 检查低容错构筑 |
| 赌博爆发 | 偏向赌局、裂隙和早期爆发 | 验证高波动构筑 |
| 招募伙伴 | 偏向旅伴营地与中期补强 | 验证队友路线 |
| 风险适应 | 前期探索、中期招募、低血恢复、后期备战 | 正式 AI 的候选升级方向 |

首轮报告反映出的路线差异已经用于正式内容：早期赌博型路线收益最高，对应赌徒线与赌博爆发 AI；中期伙伴型路线综合效用最高，对应同行线与招募伙伴 AI；高进阶需要更主动的恢复和转向，因此正式默认 AI 使用风险适应策略。三个新增精英分别绑定赌徒线、裂隙线和同行线，以沉默、封牌、金币与遗物争夺制造战术压力，生命值低于既有同阶精英。

AI 不读取未来奖励、隐藏牌序或未公开随机结果。断点工具只暂停公开状态，之后由玩家接手。

## 验收指标

- 每个难度至少跑 32 个固定种子；记录胜率、到达大层、战斗轮数、损血、金币、遗物数、队友使用率、商店抢劫率和支线完成率。
- N0–N10 的 `PI` 中位数应单调上升，但战斗轮数不应每阶增加超过 15%。
- 首领战平均轮数控制在普通战斗的 1.6–2.2 倍；超过时应增加新决策点，而非继续加生命。
- 任意路线组合中，至少两种构筑标签能达到相近首领胜率。
- 商店抢劫率建议控制在 15%–30%；选择后应显著提高本局资源上限，但明显降低后续调整能力。
- 限次队友的出战场次利用率应高于 60%，否则说明玩家无法判断其价值。
- 深渊支线完成率应高于 70%；未完成的主要原因是主动撤退，而不是导航或状态错误。

## 实现顺序

1. 用开发控制条验证断点、AI 路线和节点结算冻结当前行为；正式构建不得包含该控制条。
2. 用固定种子批量跑四大路线、三种队友和抢商店组合。
3. 根据 `PV`、`PI`、`RP` 调整节点收益与首领议程，不先改卡牌基础数值。
4. 将极端配置限制在 N7–N10，保留 N0–N6 的可读成长节奏。
5. 所有新增节点必须具备唯一执行入口、资源结算快照、回放兼容和至少一条可绕过路线。
