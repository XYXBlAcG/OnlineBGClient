# 房间派对

在牌桌工具栏直接打开「房间派对」，房主可开启派对、设置竞猜思考时间或直接解锁全部商品。设置 → 消息与互动 → 房间派对，可选择创建房间时自动开启、本机演出质量及特效帧率。

商品分为轰炸、场景、装扮、装备与观众。点击商品只选择，不扣币或发送；确认对象和费用后点击「确认发送／确认装备」，派对与房间菜单全部收起后回到牌桌观看演出。定向特效也可选择全桌（包括自己），整桌发送只扣一次费用。装扮只显示当前游戏的商品，购买后持续本局；出牌和胜负由游戏服务确认后触发。累计获得彩蛋币会解锁商品并降低成交价格，花币不会降低财富等级。

旁观者有两种：游戏规则确认已经离场的玩家，以及在加入界面选择「只旁观，不占游戏席位」的成员。等回合的玩家仍是参赛者。独立观众可以在游戏中途加入、聊天、连麦和参加派对，不掌握玩家暗牌，也不能出牌或管理房间。

竞猜在开放期间允许改押或撤回；锁定后等待公开结果。多人奖池需要两名不同观众参加，异向下注产生系统补贴；无人押中、结果提前出现或手动取消时原额退款。退出观战不会丢失托管中的下注，原身份重连后查看结果。

观众可参加抢币、合作 BOSS、弹幕接龙；所有成员可以给愿望瓶捐币并投票。尚未达到参与条件的商品会说明原因。舞台变声需要客户端已加入连麦。

特效独立于游戏动画开关。轻量、高画质、极致和纯文字在本机选择；跟随屏幕不设置固定帧率上限，实际帧率受屏幕、系统与负载影响。右下角可临时收起演出，聊天和房间菜单保持可操作。绘图在房间中预先准备，新收到的演出等待绘图就绪再完整播放；重连只恢复进行中演出的剩余部分。图形加速不可用时使用相同轨迹的兼容绘制，并明确显示状态。付费演出排队而不被普通投掷截断；未开始的项目取消后返还实际成交价。

## 人工验收

1. 在设置开启创建房间时自动启用派对；创建房间后检查开关、收支、分类和本房间规则，切换浅色、深色和手机横竖屏。
2. 开局选择流星鸡蛋，确认选择阶段没有扣币或发送；选择全桌并确认发送，检查选择面板自动关闭，再确认完整十秒演出、巨蛋与碎壳、收起与恢复；关闭游戏动画增强仍应播放派对效果。连续购买时检查排队提示、退款和普通投掷共存。
3. 启用全部商品，分别检查雷击、冰晶、列车、花朵、海浪、弹球、墨汁等演出；装备反弹伞或黑洞，再让另一成员投掷。
4. 在两个额外浏览器中使用邀请链接，勾选仅旁观加入。检查主游戏席位不变、旁观者无法出牌、可聊天和退出、重连身份不变。
5. 两位观众押不同结果；锁盘后继续游戏至产生结果。检查开奖、补贴和收支；另检查锁盘前结束对局以及服务重启的退款。
6. 两位观众参加抢币、BOSS 和接龙；愿望瓶检查不足额退款与达标后的场景投票。
7. 各游戏装备本局装扮，确认实际游戏动作触发效果。客户端连麦后购买舞台变声，检查到期恢复及手动切换变声。
8. 回放含派对的记录，检查暂停、倍速、拖动与末尾长时演出；回放不重新扣币、不改动连麦。
9. 在高刷新率屏幕选择跟随屏幕或相应帧率，并比较轻量与极致档；此项需在目标设备手动测量。
