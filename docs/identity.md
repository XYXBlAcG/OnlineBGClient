# 应用身份与数据迁移

应用标识的唯一来源是 [Tauri 配置](../src-tauri/tauri.conf.json)，原生代码通过 [身份模块](../src-tauri/src/identity.rs) 读取。显示名称、Rust 包及构建入口分别见该配置和 [Cargo](../src-tauri/Cargo.toml)。

首次启动会在新目录为空时复制旧设置、WebView 数据、对局存档和运行组件，保留旧目录；已有新数据不被覆盖。升级审核前先完全退出旧客户端，避免同时写入浏览器存储或数据库。

语音凭据使用新的系统凭据项。新项不存在时迁入旧配置，已有新配置优先；旧项保留。用户在新客户端清除配置后不会再次导入旧项。入口：[凭据服务与迁移回归](../src-tauri/src/voice.rs)。

## 人工审核

1. 退出旧版，打开新包，检查主题、快捷键、常用语、对局记录和秘塔存档。
2. 打开连麦设置，检查项目地址、API Key 与已保存状态；无需向聊天提供 Secret。实际连麦由用户测试。
3. 修改新设置并重启，确认不会被旧值覆盖；清除连麦配置后重启，确认不会重新出现。
4. 验收完成前保留旧应用数据目录。自动更新、Windows 安装注册及系统权限继续由用户手动验收。
