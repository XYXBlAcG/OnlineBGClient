# 联机运行

桌面玩家可直接使用 [一键临时公网房间](hosting.md)。手动运行服务时按 [项目入口](../README.md) 构建资源并启动房间服务。玩家在「跨网络联机」中输入服务入口，同一房间使用邀请链接或房间号加入。联机浏览器入口与客户端共用协议。

默认服务仅监听 127.0.0.1:8787；需要局域网接入时设置 HOST=0.0.0.0。公网使用 HTTPS/WSS，反向代理需要支持 WebSocket `/connect`。健康检查入口是 `/health`。

| 接入方案 | 条件 | 适用情况 |
| --- | --- | --- |
| 临时 Cloudflare Tunnel | 房主电脑、服务与隧道持续在线 | 首次跨网络验证，地址每次变化 |
| 公网服务器与 HTTPS 反向代理 | 一台服务器、域名与证书 | 稳定长期使用，推荐 |
| 虚拟局域网 | 所有玩家安装并加入同一虚拟网络 | 私人小圈子 |

临时隧道命令为 `cloudflared tunnel --url http://127.0.0.1:8787 --protocol http2`。隧道会将本地服务公开，测试时使用独立测试房间和测试昵称，结束后停止进程。已完成公网 HTTPS/WSS 路径验证，覆盖见 [验证入口](verification.md)。临时测试结束后不保留公网入口。

自建服务可直接运行 Node.js 或使用 [Dockerfile](../Dockerfile)。容器暴露 8787，持久化使用 DATA_ROOT 对应挂载目录，公网 HTTPS 在代理层配置。没有语音需求，因此不需要 STUN/TURN。

服务存档入口见 [SQLite 存储](../src/server/storage.ts)，通过 DATA_ROOT 指定数据目录。服务重启后玩家用原凭据恢复席位；真人掉线时暂停对局，全部恢复后继续。浏览器会按服务地址与房间保存自己的恢复凭据。不要清除客户端站点数据后再尝试恢复原席位。

正式购买服务器或选择托管平台时，需要结合玩家所在地与预算选择；当前不绑定付费服务。

手机入口与电脑开房联机方案见 [手机浏览器计划](mobile-browser-plan.md)。
