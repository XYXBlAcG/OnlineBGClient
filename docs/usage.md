# 本机使用统计

桌面客户端「设置 → 使用统计」显示累计、本次启动、各游戏累计和本次场次。数据仅留本机，从启用后计时，不推算旧记录。开关和单独确认的重置不影响存档、连麦配置或一般缓存。

软件使用在有可见窗口且系统未锁屏时累计；辅助窗口不重复累计；对局由应用入口统一设置计时上下文。游戏时长只计本人参与的实际对局，等待室、旁观、回放、全 AI 性能测试及断线等待不计。全部窗口隐藏或最小化后暂停。关闭统计期间不补算。

实现与口径唯一来源：[计时模型](../src-tauri/src/usage_model.rs)、[原生状态采样和持久化](../src-tauri/src/usage.rs)、[对局上下文](../src/client/usage/context.ts)、[设置](../src/client/usage/UsageSettings.tsx)。统计文件 `usage.json` 独立于缓存；重置保留此前统计备份。强制终止最多可能丢失最近一个持久化周期。

人工分别在 macOS、Windows 核对：正常游玩、打开多个辅助窗口、最小化、锁屏、休眠、重连、应用重启、关闭统计、重置及清理缓存。单元测试与本机编译不替代系统锁屏和窗口验收。
