# 使用指南

## 创建和加入

| 你要做什么 | 从哪里开始 |
| --- | --- |
| 一个人或同一电脑玩 | 大厅选游戏 → 本地对局，设置真人和 AI 席位 |
| 邀请不同网络的朋友 | 大厅 → 跨网络联机 → 临时公网入口 → 创建房间 |
| 加入朋友的房间 | 粘贴房主发来的完整邀请链接；不使用房间号 |
| 在手机玩 | 用浏览器打开邀请链接；房主电脑保持运行、联网 |
| 只用电脑提供服务 | 创建房间时启用「仅启动服务，不参与游戏」，由其他设备加入游玩 |
| 客户端连麦 | 大厅「连麦设置」，或设置 → 声音与语音；详见[语音指南](client-voice.md#配置与实际连麦) |

临时公网入口总共尝试三次。仍失败时重新创建入口；入口重新生成后，请发送新链接。临时链接依赖房主电脑，电脑退出、休眠或断网会影响联机。

进入房间后，房主在「游戏与人数」调整席位和 AI，其他玩家准备，房主开始。需要换游戏时使用房间内的游戏切换，保留房间入口；进行中的对局需先确认结束。AI 难度和出牌节奏分别设置。

## 牌桌、聊天与引导

- 游戏内的新手引导可自行打开，结合当前牌桌查看规则与操作位置。
- 专注模式隐藏顶栏和房间工具；退出专注可恢复房间操作。聊天入口仍可使用。
- 大地图使用滚轮、触摸或「移动地图」拖动；「当前位置」返回当前区域，「适配窗口」查看全图。
- 点击自己的头像使用常用语；点击其他玩家头像发送投掷特效。常用语、音效、主题和两个动画开关可在设置调整。
- 快捷键以游戏操作菜单和设置中的当前绑定为准。

## 保存、继续和回放

设置 → 数据决定是否保存对局记录，并可清理记录与缓存。回放支持播放、暂停和变速。

秘塔远征的存档在大厅「继续秘塔远征」恢复。远征存档独立于普通对局记录；清理回放不等于放弃远征。放弃存档前确认所选条目。

## 常见问题

| 问题 | 操作 |
| --- | --- |
| 朋友打不开邀请链接 | 确认房主电脑在线、服务仍在运行，并重新复制当前邀请链接 |
| 想连麦却找不到入口 | 使用客户端，点击大厅「连麦设置」；房间内打开聊天底部的语音栏 |
| 加入语音按钮不可用 | 请房主完成配置并重新创建房间，加入者不用填写项目凭据 |
| 已加入语音但别人听不到 | 默认静音；主动开麦并允许系统麦克风权限。按键说话模式还需按住设置的按键 |
| 麦克风正常但仍没有声音 | 检查耳机静音、语音音量、系统输出设备；更多见[语音指南](client-voice.md) |

首次引导与大厅入口实现见 [QuickStart](../src/client/QuickStart.tsx)，语音设置说明见 [VoiceSetupGuide](../src/client/voice/VoiceSetupGuide.tsx)。本指南不代表 Windows、手机或真实跨网通话已经完成实机验收。
