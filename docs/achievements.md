# 成就系统

成就按本地玩家席位记录。游戏成就只由真人、未开启自动操作、非训练/练习且已结束的对局解锁；导入历史回放不解锁。软件成就读取本机累计统计，包括启动次数、游玩时长、联机对局、通关次数、胜场和游戏覆盖。清除缓存不会清除成就或累计统计，也没有重置入口。

| 职责                                               | 单一实现入口                                                                           |
| -------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 稀有度、游戏成就、软件成就、回放与统计判定         | [成就领域](../src/domain/achievements.ts)                                              |
| 本机成就仓库、软件统计仓库、重复达成和清除缓存保留 | [本机存储](../src/client/storage.ts)                                                   |
| 启动、游玩时长、联机与通关统计接入                 | [进度接入](../src/client/app-progress.ts)、[客户端入口](../src/main.tsx)               |
| 成就陈列室与解锁通知                               | [成就界面](../src/client/Achievements.tsx)、[成就样式](../src/client/achievements.css) |

成就定义与条件只维护在领域目录，界面和分组从目录派生。软件成就的进度只读取本机统计，不伪造对局证据。桌面设置中的成就列表独立滚动，详情悬浮在窗口底部常驻，完整展示且不压缩列表内容；默认选中最近解锁的成就。成就可按标题、说明、游戏和稀有度搜索，选中卡片使用稀有度色描边；解锁通知带音效，标题下显示条件说明，稀有度越高停留越久。游戏内解锁时，房间消息会收到一条系统记录。成就页提供“测试成就弹窗”按钮，预览通知由[客户端入口](../src/main.tsx)统一展示。
