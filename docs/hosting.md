# 临时公网房间

在桌面客户端选择「跨网络联机」，配置玩家后点击「一键创建公网房间」。首次联机自动准备运行组件，后续复用缓存。房间就绪后复制邀请链接；好友打开链接、输入昵称并加入，无需安装客户端。

创建者保持客户端运行。「关闭房间」停止服务和公网隧道；关闭窗口可选择保留后台房间或结束并退出，托盘可重新显示窗口。「结束游戏」返回等待室。恢复已创建房间使用原席位身份，重新启动隧道会生成新邀请。

临时入口依赖 Cloudflare Tunnel 与当前网络，地址每次启动变化。固定公网服务仍可在高级设置配置。

本机房间服务使用系统分配的端口。仅联机创建者需要运行组件；离线玩家和浏览器参与者不需要 Node.js。打包时需要固定版本 cloudflared，构建脚本通过 GitHub CLI 获取并校验。运行时 Node.js 从官方源下载并校验，未依赖系统预装 Node.js。

支持目标由组件清单定义，实际平台验证见 [验证](verification.md)。移动平台尚不提供本机公网开房。
