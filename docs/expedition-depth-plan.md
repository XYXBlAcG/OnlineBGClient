# 秘塔远征：多层世界与构筑扩展方案

本方案按批次接入。当前可用内容与人工审核入口见[秘塔远征](expedition.md)，职业和牌池以[内容注册](../src/domain/expedition/content.ts)为准，主题以[大层注册](../src/domain/expedition/chapters.ts)为准。下述未开放设计仍属于后续范围；预算和胜率目标不视为已完成的平衡测量。

## 当前实现入口

[冒险推进](../src/domain/expedition/adventure.ts)负责首领奖励、驿站、共同进阶与下一张地图；[首领机制](../src/domain/expedition/boss-mechanics.ts)声明十一位首领的公开议程与阶段文案，[战斗执行器](../src/domain/expedition/rules.ts)统一执行部件、阶段、孢子、根须、热量、节拍、镜面、月潮、小兵孵化和死亡继承；[旧数据迁移](../src/domain/expedition/migration.ts)保留原远征终点；[回放](../src/domain/replay.ts)按记录的远征规则配置重建。历史首章报告与当前多层报告分别保存在[首章基准](../artifacts/expedition-chapter/benchmark.json)、[多层基准](../artifacts/expedition-depth/benchmark.json)，不能混用样本。

## 多层结构

将一次远征分为多个“大层”，每层是一张主题地图。界面使用“第 2 大层 · 第 5 节点”，区分大层与地图节点。

| 大层     | 主路径深度 | 主题规则                               | Boss 池              |
| -------- | ---------- | -------------------------------------- | -------------------- |
| 风蚀遗迹 | 12         | 护甲破绽、援护与蓄力入门               | 铁壳执政官、饥饿石像 |
| 菌蚀花园 | 14         | 孢子、再生、净化；感染也可被转化为收益 | 双生菌后、蔓根守卫   |
| 齿轮熔炉 | 14         | 过热、机关与冷却；拆机关削弱首领       | 铸造巨像、守钟机师   |
| 镜月回廊 | 16         | 预告镜像、回声、分身辨识               | 镜月女王、映身领主   |
| 沉星海渊 | 16         | 潮汐周期、蓄能、跨回合资源管理         | 潮汐神谕、深渊巨口   |
| 命运天穹 | 18         | 从已学会的机制中组合，选择本层扭曲     | 命运织者、破界之眼   |

完整主线深度为 90 个节点；每行只选择一条路线，不要求清空整张地图。捷径与可选支线会改变实际经过的节点数。

击败大层 Boss 后，依次进入个人奖励、队伍进阶选择、层间驿站和下一张地图。保留牌库、职业、金币、遗物与强化，不新建房间、不重置角色。驿站默认恢复存活角色已损失生命的 30%；倒地角色以最大生命的 30% 复起；全队倒地仍判定失败。恢复量在确认前显示。

大层奖励保证每人都有选择；所有成员处理完个人奖励后再统一切层。共享遗物延用队伍表决和领取机制。重大天赋最多进阶三次，此后提供卡牌强化、物资或有代价的契约，避免不停叠加费用减免与触发器。

第六大层后可以结算，或继续无尽攀升。无尽复用六个主题池并改变遭遇、路线、支线与词条组合，不把相同地图无限复制。每轮开始预告下一主题和附加条件。

## 地图增加决策，而非只增加点数

- 地图行宽限制在 2–5 个节点，每个节点最多两个前进出口；分叉、捷径和反向环边数量受控。绘制只加载当前大层，默认定位当前位置，并提供全图适配。
- 大层开始即公开 Boss 身份与核心规则。远处隐藏的是奖励或事件细节；可到达路线和已知风险始终可见。
- 当前节点除战斗、精英、首领、营地、商店、奇遇、宝藏、观星台、誓约碑、锻造所与隐秘裂隙外，还包括当铺、赌局、禁书库、追猎台与深渊裂隙。深渊裂隙会随机消耗队伍牌与遗物，进入 6 行随机支线层；支线出口归还原地图位置并给予额外金币与罗盘。
- 当前以征战线、补给线、秘仪线、深渊线、朝圣线、黑市线、猎杀线、禁咒线、裂隙线、赌徒线和同行线组织节点倾向；开局提供更多独立路线，每行优先放入不同节点类型，跨层捷径与反向环边形成有限环路。地图用贝塞尔曲线在大间距节点之间连接，选中节点时只强调相关路径。
- 反向跨越或跳过一层消耗共享罗盘，已探索节点再次经过时只作中转，不重复触发战斗、商店或奖励。捷径、回溯与已探索节点仍可抵达首领；锻造所提供一次定向升级，隐秘裂隙消耗罗盘开启额外宝藏。
- 支线契约会改变后续内容。例如先摧毁熔炉支线的冷却塔，Boss 的过热增长减少；放过商队，后续获得专属商店。
- 钥匙开密室，罗盘可走一次捷径；都不得成为主线通关的强制消费。任何合法选择后仍有可达 Boss 的路线。
- 随机生成后校验可达性、恢复节点间隔、连续精英数量与关键服务。首个新机制遭遇提供安全展示，不直接组合三种未知机制。
- 地图显示节点的风险、可能奖励与与当前构筑相关的标签；复杂信息放在详情，不把地图变成说明书。

## 职业与卡牌目标

最终 8 个职业，每职业 24 种独立职业牌，公共牌 24 种，共 216 种。共享牌只计入公共池，升级形态与牌组中的重复实例不重复计数。每职业至少两条能独立运作的流派，单人也能完成攻防。

| 职业   | 流派               | 特有决策                                                           |
| ------ | ------------------ | ------------------------------------------------------------------ |
| 铁卫   | 盾击、反击援护     | 为自己留盾还是保护队友；蓄盾后何时进攻                             |
| 游侠   | 印记爆发、抽弃连击 | 先铺印记还是清掉危险小怪；为队友创造攻击窗口                       |
| 炼术师 | 腐蚀中毒、再生协同 | 延迟收益、引爆时机与净化资源                                       |
| 机巧师 | 炮台、过热爆发     | 装置预热、冷却、超载；装置作为角色资源，不挤占队友头像或敌方目标位 |
| 星象师 | 观星、延迟回响     | 查看并调整有限张未来抽牌；蓄力技能的落点与回合                     |
| 祈愿师 | 祝福援护、光暗转化 | 治疗与输出转换，溢出治疗有明确转换上限                             |
| 契刃客 | 自伤收割、诅咒契约 | 用自身生命换爆发，击杀回收；不得擅自扣除队友生命                   |
| 骰术师 | 点数操控、幸运爆发 | 预留骰子、重掷与调整点数；坏骰也有稳定用途                         |

职业进阶只提供构筑倾向，不封锁另一流派的牌。先获取卡牌再调整打法，而不是开局强制选好最终构筑。奖励仍允许跳过。

骰术师示例：1 能量的“幸运射击”造成 `3＋D6` 伤害，数学期望为 6.5，范围 4–9；当前基础打击是 1 能量 6 伤害。幸运射击额外消耗一枚有限骰子，每轮获得两枚；标准能量和基础卡不依赖掷骰。具体强度还需和重掷卡、遗物及合作增益一起测试。

## 敌人与 Boss 目标

每主题 6 种普通敌人、2 种精英、2 种 Boss，共 60 种独立敌人。每层选择一个首领遭遇，多人强度通过护卫、机关和遭遇预算分配；双生首领按一个完整遭遇设计。现有 13 种整合进相应主题，目标不是在原有内容外再堆 60 种换色怪。

| 敌人机制     | 对局变化与应对                                         |
| ------------ | ------------------------------------------------------ |
| 护卫与治疗者 | 击杀顺序影响队伍损血；可以绕过护卫或先限制治疗         |
| 蓄力炮手     | 公开蓄力倒计时；集火破招、削弱或为目标提供足够保护     |
| 荆棘甲壳     | 连击需考虑反伤；单次重击、持续伤害或格挡提供不同解法   |
| 孢子寄生体   | 毒与再生相互影响；选择净化、速杀或利用感染收益         |
| 机关核心     | 先拆装置改变本场或后续 Boss；装置位置和效果清楚展示    |
| 镜像术士     | 预告将复制的动作类型，保留原动作与复制结果的区别       |
| 潮汐祭司     | 周期性爆发；提前存牌或蓄盾，而非每回合按同一顺序出牌   |
| 契约猎手     | 对公开条件作出反应；提供至少两种现有构筑可用的应对路径 |

当前十一位首领已接入公开议程或回合压力，并新增裂巢母兽的孵化队列。守门者、双生菌后和铸造巨像拥有可拆部件；生命阈值、部件死亡、议程满值和首领死亡均通过同一触发入口切换阶段、执行效果或清理所属小兵。阶段和大招代价在界面上提前展示。

首领与召唤物同时存在的目标实体先限制为四个。新增敌人必须走统一的意图、触发与效果执行器；不能按敌人名字在界面和 AI 中另写规则。

精英词条先以每只一个为主，后期最多两个。免疫整个流派、无限召唤、无回复资源时连续硬控等组合不进入生成池。针对毒、护盾和连击提供交互，不直接让某类构筑失效。

## 运气与惊喜

1. 每人每大层获得 1 枚幸运筹码，上限 2 枚，可重选一次个人奖励，或重掷一次个人事件。团队事件使用筹码需共同确认。选择何时使用是玩法的一部分。
2. 保留三选一卡牌奖励；连续三次奖励未出现玩家选择的流派标签时，第四次至少提供一项相关选项，不保证一定是稀有牌。
3. 事件公开概率和最坏结果。例如不稳定宝箱：60% 得 45 金币、30% 得一张稀有牌、10% 损失最多 4 点生命并得 20 金币。该例期望金币为 29，稀有牌收益另计，不能把两者混成虚构的统一收益分。
4. 奇遇可出现模仿怪、失物商人、诅咒折扣、队伍挑战与稀有密室。是否冒险由玩家选择，普通节点不突然变成无预告的致死判定。
5. 每层环境从有限池抽取，后期让队伍从三项中选择一项有利有弊的扭曲。例如治疗减半但奖励增加，或首回合少抽一张、第三回合获得额外能量。最多叠加两个主要环境机制。
6. 随机结果在权威端按种子抽取并记录。地图、敌人、奖励、事件使用独立随机流，并包含大层编号。刷新、重连、动画或其他人的操作不重掷结果。
7. 随机敌方意图在玩家行动窗口开启前确定并公开；不向普通攻击额外加入隐藏暴击。随机伤害卡显示伤害范围、概率与确定性部分。
8. 精英与首领按种子获得公开遭遇词条；N4 起普通遭遇也会出现词条，N8 起可叠加两个。词条包括加固、易爆、狂乱、伏击、棘化、汲取、复生与觉醒，不通过隐藏暴击制造随机失败。

## 难度曲线

以下为同级遭遇相对第一层的初始预算，尚未通过平衡实验；主题敌人的基础设计、人数预算与节点推进合并到唯一遭遇预算入口，不把数种缩放公式重复叠加。

| 大层 | 生命预算 | 攻击预算 | 主要新增压力             |
| ---- | -------- | -------- | ------------------------ |
| 1    | 1.00     | 1.00     | 基础攻防、单个机制       |
| 2    | 1.35     | 1.12     | 状态处理与敌方配合       |
| 3    | 1.75     | 1.25     | 蓄力、机关与资源保留     |
| 4    | 2.20     | 1.40     | 反应条件、分身与阶段切换 |
| 5    | 2.70     | 1.55     | 周期爆发与跨回合安排     |
| 6    | 3.25     | 1.70     | 已知机制的双重组合       |

击败 Boss 后新层开头安排恢复性的低复杂度遭遇，整层平均压力再抬升。玩家同时获得牌组强化、遗物和职业进阶；不能只增加敌方生命，让每场战斗单纯变长。

无尽以第六层内容预算为基线。第 c 轮额外生命乘数先取 `1＋0.20c`，攻击乘数取 `1＋0.10c`，并改变可预告的组合。避免指数膨胀很快变成大数字对撞。具体曲线随固定种子测试调整。

标准难度验收以“多条构筑都能工作、输局有可解释原因”为核心。通关率、战斗轮数和真人体验分别记录；不会把某个 AI 的通关率当成真人难度。

远征另设 N0–N10 累积阶位，定义见[进阶规则](../src/domain/expedition/ascension.ts)。N4、N8 增加遭遇词条，N5 增加首领小兵，N7 增加路线代价，N10 同时提高首领生命并提前首领议程。补偿只提供少量金币、生命、幸运或罗盘，不抵消高阶负面；界面同时展示负面与补偿。

## 卡牌与阅读

同一张牌的强化等级、可强化条件及成长以[内容规则](../src/domain/expedition/content.ts)为唯一入口，前后对比复用[规则预览](../src/client/expedition/presentation.ts)。资源收益具有上限；负面热量代价不因强化而增大。浅深色牌纸、正文和辅助文字统一由[牌面样式](../src/client/expedition/cards.css)管理。

## 后续未开放内容

后两个主题、无尽、流派保底和环境扭曲仍按后续批次接入；当前不显示尚未完成的选择项。职业资源统一由[资源规则](../src/domain/expedition/resources.ts)执行，状态牌由[状态牌注册](../src/domain/expedition/status-cards.ts)声明。

## 工程与验证

- [冒险状态](../src/domain/expedition/adventure-types.ts)增加大层编号、全局深度、当前主题、路线标志及进阶记录；地图尺寸与职业编号约束由内容注册表派生。
- [冒险推进](../src/domain/expedition/adventure.ts)统一处理 Boss 奖励、驿站、投票和切层，保留同一 runId 与房间。节点 ID 和随机流包含大层前缀。
- 职业、卡牌和世界内容按主题／职责拆分，依旧只由规则层执行。说明、伤害范围预览、敌方意图和 AI 模拟复用同一类型与执行器。
- 远征 AI 的能力档位共用合法动作生成器；档位差异只来自公开信息的路线评估精度与决策噪声，不读取隐藏奖励、牌序或未来随机结果。能力较强的 AI 会更主动评估未探索环路、资源足够的裂隙和低血量时的恢复节点。
- 既有未完成存档先备份并做一次性数据迁移，保留当前地图、进度、牌库和行装；已完成记录不自动改成新的未完成远征。先核对旧回放的实际数据再制定迁移，不能使用新随机结果重写历史。
- 长局只保留当前地图的渲染数据，已完成大层使用摘要；回放继续按需还原。AI 复用现有 Worker、线程预算和取消机制，按公开信息评估新机制，不偷看未来奖励和随机结果。
