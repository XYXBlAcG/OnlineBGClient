# 台球 3D 版本计划

状态：阶段 1、2 的可玩 3D、碰撞/落袋音效、袋口下落、AI 试玩页、完整球体姿态、袋角几何、跳球/扎杆和台球新手引导已实现；移动端实机性能与观战/回放导播仍待继续。3D 只替换渲染层，不改变权威规则和房间协议。2D 渲染器见 [PoolTable](../src/client/pool/PoolTable.tsx)，3D 渲染器见 [PoolTable3D](../src/client/pool/PoolTable3D.tsx)，可玩页面见 `?dev=poolplay`，场景调试页见 `?dev=pool3d`。

## 结论

3D 版本采用 **Three.js 渲染 + 现有 2D 物理**：

- 台球运动仍然发生在二维台面，服务端使用 planck 计算权威物理。
- 3D 只负责桌面、球体、灯光、阴影、球杆、相机和击球录像播放。
- 不把物理改成 3D，避免规则、回放、AI 和网络同步全部重做。
- 2D 版本持续保留，3D 作为可选渲染器和回退目标。

## 当前实现

- 渲染选择：[PoolGame](../src/client/pool/PoolGame.tsx) 提供 `auto / 2D / 3D`，自动模式只在桌面指针、WebGL 可用且宽度足够时选择 3D；初始化失败自动回退 2D。
- 共享界面：[PoolTableShell](../src/client/pool/PoolTableShell.tsx) 负责模式、轮次、计时、力度条、杆法、杆身角度、预计轨迹、视角切换和相机复位。
- 2D 渲染：[PoolTable](../src/client/pool/PoolTable.tsx) 负责 Canvas 桌面、球杆、预计轨迹、击球反馈和摆球。
- 3D 渲染：[PoolTable3D](../src/client/pool/PoolTable3D.tsx) 负责射线瞄准、左键蓄力、右键/中键旋转、观察模式左键旋转、滚轮缩放和 2D 回退。
- 3D 场景：[PoolScene3D](../src/client/pool/render3d/PoolScene3D.ts) 负责桌面、球体、球杆、幽灵球、瞄准线、灯光、阴影、击球回放、碰撞/袋口事件和尺寸校验。
- 输入状态机：[use-pool-aim](../src/client/pool/use-pool-aim.ts) 统一 2D/3D 的瞄准、锁定方向、向后拖动蓄力、旋转、杆身角度、摆球和光标反馈。
- 轨迹预测：[prediction.ts](../src/client/pool/prediction.ts) 生成白球路径、幽灵球和多次碰库反弹。
- 音效：[audio.ts](../src/client/pool/audio.ts) 生成击球、球球碰撞、库边和落袋音效，音量使用全局音效音量，可在设置中关闭。
- 物理手感：[physics.ts](../src/domain/pool/physics.ts) 使用三维角速度、滑动/滚动摩擦、杆法旋转、球球/库边切向摩擦、完整姿态帧、袋角几何、跳球/扎杆/masse、碰撞事件、停止阈值和 8 秒上限，回放速率统一为 1.5 倍。
- 试玩页：[PoolPlayPreview](../src/client/dev/PoolPlayPreview.tsx) 提供玩家 1 对 AI 的完整 3D 对局。
- 调试页：[Pool3DPreview](../src/client/dev/Pool3DPreview.tsx) 保留 8-Ball/9-Ball 切换、演示开球、调试 HUD 和错误重试。
- 移动端：粗指针强制 3D 时降低像素比、阴影和球体细分。
- 新手引导：[pool/guide.ts](../src/client/pool/guide.ts) 使用真实台面、力度、杆法、杆身角度、预计轨迹、渲染和相机目标。
- 3D 光标：瞄准模式直接同步 canvas 光标，白球不可移动时显示 `not-allowed`，自由球可移动时显示 `grab/grabbing`。
- 更真实的旋转、摩擦、库边和袋口方案见 [台球 3D 物理引擎计划](pool-3d-physics-plan.md)。
- Three.js 只通过动态 import 进入 3D chunk，不进入生产构建初始 chunk。

当前仍不包含：

- 球号/花色贴图的最终 PBR 美术。
- 移动端真机性能分级和完整触摸体验验收。
- 观众模式、回放时间轴、相机导播和跟球镜头。

## 黑屏与页面高度根因

问题不是 Three.js 不可用，而是原型缺少布局和初始化契约：

- 3D 页面根节点同时带有 `.app-shell` 和 `.pool-preview`，自身没有显式 `box-sizing` 和覆盖 `min-height`，`100dvh` 加 padding 后出现全局滚动。
- 3D 宿主没有确定的剩余高度，canvas 仅靠 `height: 100%` 依赖父级计算结果。
- 渲染器在构造时立即读取宿主尺寸；布局未完成时尺寸为 0，直接返回后没有可见状态。
- canvas 没有绝对定位填满宿主，也没有 loading/error/回退界面，失败和正常黑屏无法区分。
- 没有调试 HUD 和自动化契约测试，无法定位是 WebGL 失败、尺寸为 0、相机问题还是没有首帧。

阶段 0 已针对这些根因修正，验收项见下文。

### Poolians 的关键设计

- **2D/3D 并存**：2D 用于休闲和低端设备，3D 用于沉浸感，不强制所有玩家用同一种渲染。
- **瞄准优先**：鼠标移动直接控制球杆方向；按下并向后拖动蓄力；右键锁定球杆后再调旋转。输入顺序清晰，不会“点一下就直接发球”。
- **旋转是独立控件**：高低杆/侧旋有独立面板，不是藏在设置里。
- **相机服务操作**：滚轮缩放，镜头可以观察球路，但不能和瞄准争夺鼠标。
- **规则模式清晰**：8-Ball、9-Ball、15-Ball、Killer、Rotation、Blackjack、14+1；首版不需要全做，但模式和规则要在房间里可见。
- **练习与 AI**：AI 难度分层，先让玩家在练习中熟悉力度和旋转。
- **社交围绕牌桌**：头像、资料、聊天、好友、赠送、排行榜、赛事、Pub/组队模式，不是独立社交软件。

### 对本项目的取舍

- 借鉴 Poolians 的操作顺序、旋转控件、相机与练习模式，不复制其资源、代码或商业系统。
- 借鉴 Polymatic 的 MIT 物理和 AI 组织方式；如复制实质代码，保留版权声明。
- Tailugebilliards 只参考论文、公式和架构，不复制 GPL 代码。
- 首版继续使用 2D 物理 + 3D 渲染，不把物理改成 3D。

## 场景设计

### 桌面

- 台面尺寸直接使用 `POOL_TABLE`：2.24m × 1.12m。
- 球半径、袋口半径与 2D 一致。
- 木质外框、台呢、六个袋口、库边。
- 台呢使用程序化纹理或 CC0 布料纹理，不引入来源不明的素材。
- 后续可以加球桌编号、房间主题和灯光颜色。

### 球体

- `SphereGeometry` + `MeshPhysicalMaterial`。
- 白球、实色、花色、8 号球由程序化 canvas 贴图生成。
- 数字和花色先使用 canvas 贴图，后续可换成更精细的 PBR 贴图。
- 阴影、接触高光和轻微 roughness，避免塑料感。
- 球号朝向会在滚动时旋转；首版可以只保证颜色/花色正确。

### 灯光

- HemisphereLight：环境底色。
- DirectionalLight：主光和阴影。
- PointLight：侧后方轮廓光。
- 少量环境反射，不使用重型后处理作为默认。
- 移动端降低阴影分辨率和光源数量。

### 相机

- 默认斜俯视，看向台面中心。
- 轨道旋转、缩放、限制最低/最高俯角。
- 相机复位。
- 后续增加：
  - 顶视/斜视切换。
  - 击球跟随镜头。
  - 结算阶段环绕镜头。
  - 观众模式自动导播。

## 输入与瞄准

3D 输入不能直接照搬 2D Canvas 坐标，需要从相机射线打到台面平面：

```text
pointer → Raycaster → 台面 y=0 平面 → 台面坐标 → 瞄准方向
```

2D 和 3D 共用 [use-pool-aim](../src/client/pool/use-pool-aim.ts)，渲染器只负责把屏幕坐标转换成台面坐标：

- 鼠标移动：球杆绕白球旋转。
- 鼠标在球右侧：球杆在左侧指向白球，击球方向向右。
- 按下鼠标：锁定方向并开始蓄力。
- 向后拖动：按拖动在击球反方向上的投影计算力度，横向移动不会偷偷改变方向。
- 松手：击球；拖动过短则取消。
- 指针捕获：拖出画布不会取消蓄力。
- 球杆尖与白球之间显示虚线，默认显示短瞄准线。
- 可选预计轨迹：白球路径、幽灵球和碰库反弹，默认关闭。
- 自由球：点击或拖动白球放置，放置位置随击球动作一起提交。

### 相机与瞄准解耦

- 2D 没有相机，3D 瞄准模式下左键用于瞄准和蓄力。
- 3D 瞄准模式可用右键/中键/双指旋转；HUD“转动视角”进入观察模式后可用左键拖动旋转。
- 相机缩放不改变瞄准方向。
- 视角复位使用平滑插值，不要求玩家每杆手动复位。

### 手感取舍

- **瞄准和蓄力分离**：移动鼠标只负责方向，按下后锁定方向，向后拖动只负责力度，避免蓄力时方向漂移。
- **鼠标指向击球方向**：鼠标在白球哪一侧，击球就朝哪一侧，球杆自动停在白球另一侧。
- **进度可见**：力度条实时显示，松手立即出杆并播放击球音效，服务端返回前也有明确反馈。
- **路径可读**：默认显示短瞄准线；开启预计轨迹后显示白球路径、幽灵球和碰库反弹。
- **镜头不抢操作**：3D 左键始终属于瞄准，右键和滚轮才操作相机。
- **回放不拖沓**：滚动阻力和停止阈值让球在合理时间内停稳，回放统一 1.5 倍。

## 击球动画与手感

- 使用 `PoolShot.frames`，60Hz 关键帧，包含位置、高度和四元数姿态，2D/3D 共用 `interpolateBalls`。
- 回放速度统一为 1.5 倍；物理增加滚动阻力、合理停止阈值和 8 秒上限，避免每杆都跑满 12 秒。
- 出杆速度上限下调约 10%，整体力度比上一版更柔和。
- 松手后立刻播放 160ms 球杆出杆动画和击球音效，用反馈覆盖服务端计算延迟。
- AI/对手击球前播放 260ms 球杆出杆动画，再从击球录像帧播放，避免球凭空移动。
- 球体使用服务端姿态帧中的四元数旋转，2D 仍按位移方向推导滚动。
- 落袋音效跟随击球帧时间播放；3D 袋口下落动画已接入。
- 抬杆击球会产生跳球，抬杆配合侧塞会产生弧线；3D 球杆同步抬高。
- 犯规、进球、8 号球绝杀使用现有舞台/提示，不新增权威状态。
- 更真实的旋转、摩擦、库边和袋口模型见 [台球 3D 物理引擎计划](pool-3d-physics-plan.md)。

## 性能与回退

- Three.js 只通过动态 `import()` 加载，禁止进入大厅首屏。
- 桌面：高分辨率、阴影、环境光；移动端：低分辨率、低阴影、减少光源。
- 提供 `3D / 2D / 自动` 设置；WebGL 失败或 canvas 尺寸持续为 0 时自动回退 2D。
- 低帧率时提示切换 2D，不强制中断对局。
- 3D 场景只更新球体位置和姿态，不重建对象。
- 阶段 0 在切换模式或重试时重建场景，并统一释放几何体、材质和贴图；阶段 1 起改为复用场景对象。

### 人工验收

由用户执行，不由自动化代替：

1. 打开 `?dev=poolplay`，用玩家 1 对 AI 打一局 8-Ball 或 9-Ball；AI 击球前应先看到球杆出杆动画，再播放球体动画。
2. 正式房间进入台球，确认桌面端默认 3D、手机端默认 2D；设置 → 界面显示 → 台球渲染可切回自动。
3. 3D 中移动鼠标瞄准，按住左键向后拖动蓄力，松手击球。
4. 鼠标在球右侧时，球杆在左侧、击球方向向右。
5. 蓄力时横向移动不改变方向；拖出画布后仍能完成蓄力。
6. 转动视角：点 HUD“转动视角”后左键拖动，或用右键/中键拖动；滚轮缩放，点“视角复位”。
7. 打开“预计轨迹”，确认白球路径、幽灵球和多次碰库反弹。
8. 左塞/右塞击球，确认被撞球有轻微甩球、白球撞库方向随旋转变化。
9. 点击 HUD 的“2D”再切回“3D”：已结束的动画不重播；击球中切换应从当前进度继续。
10. 犯规获得自由球后，点击或拖动白球放置，确认击球从放置位置开始；不能移动时把鼠标移到白球上应显示禁止光标。
11. 确认击球、球球碰撞、库边和落袋音效；在设置中关闭“台球音效”后确认静音。
12. 打开新手引导，确认能定位顶部状态、台面、力度、杆法、杆身角度、预计轨迹、2D/3D、3D 转动视角和已进袋球。
13. 确认落袋时球先到达袋口，再下沉缩小，不在半路消失；连续打进几杆后，已进袋的球不会再回到桌面。
14. 贴边瞄准时确认球杆不会穿过桌沿。
15. 选择 30°/60° 抬杆并加大力度，确认白球能跳过前面的球；配合左右塞确认弧线。
16. 观察 3D 球体滚动和球号朝向，确认与运动方向一致。
17. 打开 `?dev=pool3d&debug=1`，确认渲染尺寸非 0、FPS、draw calls 和最近 resize 正常。
18. 手机横屏/竖屏不撑高页面；WebGL 失败或尺寸为 0 时回退 2D。

## 风险

| 风险            | 控制                                                |
| --------------- | --------------------------------------------------- |
| Three.js 包体大 | 动态加载、只进 3D chunk、构建检查初始 chunk         |
| 手机 GPU 压力   | 阴影/分辨率/光源分级，默认轻量，自动回退 2D         |
| 3D 瞄准不准     | 射线求交平面 + 与 2D 共享瞄准状态机                 |
| 相机遮挡球桌    | 限制俯角、相机复位、关键球高亮                      |
| 美术素材版权    | 程序化材质或 CC0，来源记录在 ACKNOWLEDGEMENTS       |
| 规则和 3D 分叉  | 3D 只读 `PoolView`/`PoolShot`，不修改规则和权威状态 |
