# 游戏动画方案演示

[打开独立 demo](../artifacts/review/game-motion-lab.html)。复用现有游戏组件导出的牌面、棋子和地图，支持八款游戏、播放／暂停、倍速、进度拖动和低动态模式。全部资源内嵌，可直接在浏览器打开。

## 审核重点

| 场景 | 新方案的视觉目标 |
| --- | --- |
| 跳棋 | 单个棋子逐跳抬起、落地；小范围阴影体现高度；路线与落点清楚，避免终点已经有棋子而副本还在飞 |
| UNO／斗地主 | 选牌轻微抬起，明确离手与落位；手牌平滑填补空位；摸牌以牌背移动，到本人手牌后交接实体 |
| 三国杀 | 使用杀后，出牌区向目标发出短响应指向；体力数字只在目标附近反馈，避免全屏震动 |
| 璀璨宝石 | 筹码错峰移动，颜色保留；到达时增加演示数量；发展卡入收藏时由实体接管 |
| 卡坦岛 | 建造位置先有小范围确认，村庄从地基落下；不改变地图点击坐标 |
| 毒药 | 出牌落锅、超限提示与收牌方向连贯可辨认 |
| 飞行棋 | 骰子短过渡后显示预设结果，飞机沿可见路线移动并明确落位 |

默认比较「当前增强效果重现」与「新方案」。可勾选「显示原版节奏参考」增加第三列。前两者是关键反馈的参考演示，不能视为完整客户端动画的逐帧还原；局面、动作和结果均为预设，不执行完整游戏规则。正式客户端入口见 [体验文档](ui-motion-plan.md)，demo 为独立的预设场景展示。

动作来源见 [语义事件](../src/client/game-motion-events.ts)，播放与实体交接见 [TableAnimator](../src/client/motion/table-animator.ts)。权威局面立即生效，表现层可中断、快进与清理；不增加出牌等待，不展示他人的隐藏信息。客户端开关与现有入口见 [体验文档](ui-motion-plan.md)。
